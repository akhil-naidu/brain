## Why

Users often want more space for the conversation. A keyboard toggle for the sidebar completes the shortcut set with New chat and Search.

## What Changes

- Add `⌘/Ctrl+B` to toggle the chat sidebar open/closed.
- Show the shortcut on the open/close sidebar controls.
- Same toggle path as the existing sidebar buttons.

## Capabilities

### New Capabilities

- `sidebar-toggle-shortcut`: Keyboard shortcut to show or hide the chat sidebar.

### Modified Capabilities

- (none)

## Impact

- Keyboard helper + shell listener
- Sidebar / header button hints
- Tests
