Open **`/models`** to see what is available in chat.

## Built-in (Command Code)

When `COMMAND_CODE_API_KEY` is set on the host, curated models appear as **Built-in** under Available in chat. They are not edited on this page.

If no Command Code key and no custom models exist, chat shows an unavailable empty state until you configure one path.

## Composer picker

The chat composer remembers your last model. Choose a built-in or [custom model](/docs/models/custom-models).

## Tools catalog

Connection tools live on **`/tools`** — see [Tools catalog](/docs/models/tools-catalog).
