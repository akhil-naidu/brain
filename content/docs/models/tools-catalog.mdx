**`/tools`** is the hub for:

- Connection status (needs setup / needs sign-in / connected)  
- **Set up**, **Connect**, **Disconnect**  
- Enable for chat  
- Browse tools loaded from a connected MCP server  

Pair with [Connections overview](/docs/connections) for per-app setup details.
