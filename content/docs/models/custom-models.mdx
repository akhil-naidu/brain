---
title: Custom models
description: Add OpenAI-compatible endpoints for a workspace or the whole instance.
---

On **`/models`**, add a custom model:

1. Display name  
2. Base URL (OpenAI-compatible)  
3. Provider model id  
4. Optional API key and context window  

Presets (Ollama, LM Studio, …) and **Fetch models** discovery help fill fields.

## Scope

| Scope | Who can add | Badge |
| --- | --- | --- |
| This workspace | Workspace admin | This workspace |
| Entire instance | Instance admin | All workspaces |

Custom models merge with Command Code entries in the composer catalog.
