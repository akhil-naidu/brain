---
title: Playbooks
description: Save reusable prompts and run them from chat or schedules.
---

Playbooks are saved **label + prompt** pairs for your user in the active workspace.

Open **`/playbooks`**.

## Limits

- Up to **12** playbooks  
- Label ≤ 60 characters  
- Prompt ≤ 4000 characters  

## Actions

| Action | Result |
| --- | --- |
| **Create / Edit / Delete** | Manage the library |
| **Run** | Opens `/chat` with the prompt ready |
| **Schedule** | Deep-links to `/schedules` for that playbook |

Empty chat welcome chips can surface playbooks as quick starts. Composer `/` and `@` commands can open or run playbooks too.
