Open **`/schedules`**.

## Playbook schedules

- Pick a playbook  
- Set time, timezone, and enable  
- Optional Slack delivery (when Slack is connected)  
- **Run now**, pause all / resume all, or delete  

Automatic runs need host env: `BRAIN_INTERNAL_TOKEN` and usually `BRAIN_INTERNAL_URL`. See [Environment variables](/docs/reference/environment).
