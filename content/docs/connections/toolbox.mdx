**Auth:** HTTP MCP URL + optional bearer token.

## Admin: Set up

1. Deploy [MCP Toolbox](https://mcp-toolbox.dev/documentation/getting-started/mcp_quickstart/) with an HTTP endpoint  
2. **`/tools`** → **MCP Toolbox** → **Set up**  
3. Paste client URL (+ optional bearer)  
4. Enable for Agent chats  

Env fallback: `TOOLBOX_MCP_URL`, `TOOLBOX_MCP_TOKEN`.

Client docs: [Connect to MCP client](https://mcp-toolbox.dev/documentation/connect-to/mcp-client/).
