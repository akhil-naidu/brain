# Introduction

**Brain** is a self-hosted work assistant: browser chat, MCP connections, workspaces, playbooks, and schedules — running on **your** host with **your** Postgres.

This documentation is for:

- **End users** — chat, connections, playbooks, and day-to-day workflows
- **Self-host operators** — install, configure, upgrade, and keep Brain healthy
- **Enterprise admins** — workspaces, SSO/SCIM, and policies (expanding over time)

## What Brain is not

Brain stays **self-hostable**. Core paths do not require Vercel AI Gateway, Neon, Vercel Connect, or Vercel Sandbox. You bring Postgres, a model API key, and a host (Docker, Dokku, dflow, or similar).

## Docs vs engineering notes

This `/docs` site is the customer manual. OpenSpec specs and `docs/superpowers/` plans in the repository are for contributors implementing Brain — they are not part of this site.
