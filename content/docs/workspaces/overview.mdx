A **workspace** scopes chats, playbooks, schedules, and MCP credentials. Most users start with a personal workspace; teams create shared workspaces.

## Switch or create

Open **`/workspaces`** to:

- Switch the active workspace  
- Create a new workspace (when instance policy allows)  

License entitlements may limit multi-workspace features on licensed hosts — see [License](/docs/enterprise/license).

## Settings

**`/workspaces/settings`** (team workspaces):

| Tab | Purpose |
| --- | --- |
| People | Members and roles |
| Invites | Invite links |
| Sign-in | SSO and SCIM (licensed) |

Legacy URLs under `/settings/workspace` redirect here.

## Roles

| Role | Capabilities |
| --- | --- |
| **Owner** | Full control; transfer ownership |
| **Admin** | Manage members, invites, SSO/SCIM, tool Set up |
| **Member** | Use chats and Connect after apps are configured |

See [Members and invites](/docs/workspaces/members-and-invites).
