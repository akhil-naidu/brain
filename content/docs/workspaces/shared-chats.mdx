---
title: Shared chats
description: Collaborate on the same chat thread with turn locks and revision checks.
---

In a **team** workspace you can:

- Start a **New shared chat** from the sidebar  
- **Share** an existing personal chat with the team  

Everyone with access opens the same thread. MCP grants remain **per user** — each member must Connect apps they want the agent to use on their turns.

## Concurrency

Shared chats enforce:

| Mechanism | Behavior |
| --- | --- |
| **Turn lock** | Only one member runs an agent turn at a time (lock TTL ~5 minutes; abandoned locks expire) |
| **Revision checks** | Saves that race another member’s update are rejected |

Messages you may see:

- *Another member is currently running a turn in this chat.*  
- *Chat was updated by another member. Refresh and try again.*  

Personal chats do not use turn locks.
