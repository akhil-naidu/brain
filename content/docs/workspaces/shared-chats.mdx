---
title: Shared chats
description: Collaborate on the same chat thread inside a team workspace.
---

In a **team** workspace you can:

- Start a **New shared chat** from the sidebar  
- **Share** an existing personal chat with the team  

Everyone with access opens the same thread. Brain uses concurrency / revision checks so simultaneous edits stay consistent.

Personal chats stay private until shared. Projects and history still respect the active workspace — see [History and projects](/docs/chat/history-and-projects).
