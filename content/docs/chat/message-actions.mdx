title: Message actions
description: Copy, regenerate, edit, retry, read aloud, and export.
---

## On a user message

| Action | What it does |
| --- | --- |
| **Edit** | Change the last user message and resend (⌘↵ / Ctrl+Enter when editing) |
| **Retry** | After a failed turn, resend the last user prompt |

## On an assistant message

| Action | What it does |
| --- | --- |
| **Copy** | Copy that reply as Markdown |
| **Regenerate** | Generate a new assistant reply for the same prompt |
| **Read aloud** | Browser text-to-speech; click again to stop |
| **More** | Timestamp, copy/download helpers |

## Whole chat

From the chat header / overflow:

- **Copy chat as Markdown**  
- **Download chat as Markdown** (filename like `brain-chat-…`)  

## Tool calls in the stream

Tool groups expand to show arguments and results. Authorization challenges appear mid-turn when an MCP app needs you to sign in — open the authorize URL, then continue.
