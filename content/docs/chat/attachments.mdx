---
title: Attachments
description: Attach images, PDFs, and text files to a chat turn.
---

Attach files from the composer via:

- File picker  
- Paste (images)  
- Drag and drop onto the composer  

Supported families typically include images, PDF, and text/code. Oversized or unsupported types are rejected with a clear error.

Attachments are sent with the user message as multipart content for the model to read. They are not a permanent file drive — each turn carries what you attach for that send.
