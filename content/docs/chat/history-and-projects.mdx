## Chat list

The sidebar lists recent chats for the **active workspace**. Use search to filter by title.

Full list management: **`/chats`**.

### Search

- Matches **chat titles** only (case-insensitive substring) — not message bodies  
- Scoped to the **active workspace**  
- Shortcuts: **⌘K** / **Ctrl+K**, or **/** when focus is not in an input  
- Empty state: *No chats match*  

Docs site search (`/docs`) is separate and indexes documentation pages.

### Row actions

- Rename  
- Pin / unpin  
- Archive  
- Delete  
- Share (personal → shared with the team workspace, when allowed)  
- Move to project / create project  

## Projects

Projects are named folders for chats.

- Browse and create: **`/projects`**  
- Start a chat already scoped to a project from the sidebar or composer commands  
- Deleting a project returns its chats to Recent (chats are not permanently deleted with the project)

## Shared chats

In a **team** workspace you can create shared chats or share an existing personal chat. See [Shared chats](/docs/workspaces/shared-chats) for turn locks and conflict messages.
