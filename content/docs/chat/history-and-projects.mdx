## Chat list

The sidebar lists recent chats for the **active workspace**. Use search to filter by title.

Full list management: **`/chats`**.

### Row actions

- Rename  
- Pin / unpin  
- Archive  
- Delete  
- Share (personal → shared with the team workspace, when allowed)  
- Move to project / create project  

## Projects

Projects are named folders for chats.

- Browse and create: **`/projects`**  
- Start a chat already scoped to a project from the sidebar or composer commands  
- Deleting a project returns its chats to Recent (chats are not permanently deleted with the project)

## Shared chats

In a **team** workspace you can create shared chats or share an existing personal chat. Multiple members can open the same thread; Brain uses concurrency / revision checks so edits stay consistent. See [Shared chats](/docs/workspaces/shared-chats).
