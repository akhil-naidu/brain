Open **`/chat`** after sign-in. The shell has three main areas:

1. **Sidebar** — workspaces, chat history, search, new chat, projects  
2. **Conversation** — messages, tool calls, reasoning, authorization prompts  
3. **Composer** — mode, model, attachments, tools menu, message box  

If no model path is available (no `COMMAND_CODE_API_KEY` and no custom models), Brain shows a clear “chat unavailable” empty state — configure models under [Models](/docs/models) or set the Command Code key.

## New chat

- Sidebar **New chat** (or **New shared chat** in a team workspace when allowed)
- Keyboard: **⌘⇧O** / **Ctrl+Shift+O**

## Empty chat

Welcome chips suggest starter prompts. Your saved [playbooks](/docs/playbooks-and-schedules/playbooks) can also appear as quick starts.
