---
title: Chat shortcuts
description: Keyboard shortcuts inside the signed-in app.
---

| Shortcut | Action |
| --- | --- |
| **⌘K** / **Ctrl+K** | Focus chat search in the sidebar |
| **/** | Focus chat search when not typing in an input (slash shortcut) |
| **⌘⇧O** / **Ctrl+Shift+O** | New chat |
| **⌘B** / **Ctrl+B** | Toggle sidebar |
| **Shift+Tab** | Cycle Ask ↔ Agent mode |
| **⌘↵** / **Ctrl+Enter** | Confirm edit of last user message |

Docs site search uses **⌘K** / **Ctrl+K** on `/docs` pages (separate from chat search).
