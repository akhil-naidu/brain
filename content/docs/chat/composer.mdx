The composer sits under the conversation.

## Model picker

Choose a curated Command Code model or a [custom model](/docs/models/custom-models). Selection is remembered for later chats.

## Tools menu (Integrations)

- Toggle which MCP apps are **enabled for this chat**  
- Peek loaded tools for a connected app  
- **Manage tools** opens **`/tools`**  

Grants and credentials are per signed-in user × active workspace. See [Connections overview](/docs/connections).

## Slash / mention commands

Use `/` or `@` in the composer for shortcuts such as:

- Enable or jump to connections  
- Open or run [playbooks](/docs/playbooks-and-schedules/playbooks)  
- New chat in a [project](/docs/chat/history-and-projects)  
- Open [schedules](/docs/playbooks-and-schedules/schedules)  

## Send and stop

- Enter sends (⇧Enter for newline — follow on-screen hints)  
- **Stop** cancels an in-flight turn (cooperative cancel, then hard stop if needed)  

## Attached repo

In Agent mode, bind a GitHub repository for sandbox coding — [Attached repo](/docs/chat/attached-repo).
