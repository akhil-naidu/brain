---
title: Settings map
description: Where to find account, workspace, tools, models, and instance settings.
---

| Path | Who | Purpose |
| --- | --- | --- |
| `/settings/account` | Any user | Profile and sessions (revoke other devices) |
| `/workspaces` | Any user | Switch or create workspaces |
| `/workspaces/settings` | Workspace admin | People, invites, SSO/SCIM |
| `/tools` | Users (+ admins for Set up) | MCP connections and loaded tools |
| `/models` | Users (+ admins for custom) | Built-in and custom models |
| `/playbooks` | Any user | Saved prompts |
| `/schedules` | Any user | Morning brief and playbook timers |
| `/chats` | Any user | Full chat list |
| `/projects` | Any user | Project folders for chats |
| `/settings/instance` | Instance admin | License, policies, host users |
| `/docs` | Anyone | This documentation (public) |
