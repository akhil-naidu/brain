## Chat app

| Shortcut | Action |
| --- | --- |
| **⌘K** / **Ctrl+K** | Focus chat search |
| **/** | Focus chat search when not in an input |
| **⌘⇧O** / **Ctrl+Shift+O** | New chat |
| **⌘B** / **Ctrl+B** | Toggle sidebar |
| **Shift+Tab** | Cycle Ask ↔ Agent |
| **⌘↵** / **Ctrl+Enter** | Confirm edited user message |

## Docs (`/docs`)

| Shortcut | Action |
| --- | --- |
| **⌘K** / **Ctrl+K** | Search documentation |
