---

Enterprise features are managed by **instance admins** and **workspace admins**.

| Topic | Where |
| --- | --- |
| License & entitlements | [`/settings/instance`](/docs/enterprise/license) |
| Signup / workspace policies | [Instance policies](/docs/enterprise/instance-policies) |
| Host user password reset | [Instance users](/docs/enterprise/instance-users) |
| Company SSO | [SSO](/docs/enterprise/sso) |
| Directory provisioning | [SCIM](/docs/enterprise/scim) |

**Unlicensed** self-host installs keep features unlocked (self-host defaults). Pasting a **BRAIN1** license applies entitlement gates shown as chips on the instance page.
