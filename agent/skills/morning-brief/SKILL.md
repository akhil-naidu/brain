# Morning brief

Produce a short, high-signal status brief across enabled work apps. Brain is not an IDE — this is connection/work status only.

## Procedure

1. Use only connections that are enabled for the turn and already authorized. If one is disabled or needs setup/sign-in, skip it and mention that briefly — never invent items.
2. Pull a small amount of high-signal data with tools (tasks due/blocked, important Slack, email that needs reply, dFlow health, urgent Linear/ClickUp items) rather than dumping raw lists.
3. Answer as a short brief with clear sections and concrete next actions.
4. Confirm before create/update/send actions.

## Style

- Lead with what needs attention today.
- Keep each section to a few bullets.
- Name concrete ids/titles when known; do not fabricate.
