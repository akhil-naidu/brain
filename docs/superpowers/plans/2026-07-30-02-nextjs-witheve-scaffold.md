### Task 2: Open anonymous user channel auth

**Files:**
- Modify: `agent/channels/eve.ts`

**Interfaces:**
- Produces: every request authenticated as `principalType: "user"` without credentials
- Consumes: `eve/channels/eve`, `eve/channels/auth` types

- [x] **Step 1: Replace channel auth with fixed anonymous user**

```ts
import { eveChannel } from "eve/channels/eve";
import type { AuthFn } from "eve/channels/auth";

/** Local/trusted open access — not for public internet without a real AuthFn. */
const anonymousUser: AuthFn<Request> = () => ({
  attributes: {},
  authenticator: "anonymous",
  issuer: "local",
  principalId: "anonymous",
  principalType: "user",
});

export default eveChannel({
  auth: [anonymousUser],
  uploadPolicy: "disabled",
});
```
